### Adrian Lungu

Ohayo!

Go engineer building developer infrastructure — mostly around AI agents these days,
terminal UIs, and the plumbing that makes both less painful.

#### Currently building

- **[Flatte](link)** — a Go TUI framework betting on immediate-mode rendering over
  the Elm architecture. Fewer message loops, more direct state.
- **[Gocker](https://github.com/lunguini/gocker)** — a Docker-compatible CLI and
  API daemon for Apple's `container` on macOS. Point your existing Docker tooling
  at it and it just works.
- **[Rum](https://github.com/lunguini/rum)** — a Whisky-fork Wine wrapper for macOS,
  built with SwiftUI. (Maintainer.)

More cooking, including a Go AI harness, and self-hosted memory substrate for AI agents — 
not quite ready to show yet.

#### Elsewhere

Contributor across the Go ecosystem — ogen, Dynamo, Taskfile, GraphQL, and others I've lost track of. Currently going deeper on ML. Also keep a few Homebrew taps and a Zed theme somewhat alive.

*Outside of code: music, manga, DIY, and lately designing furniture with an (un)reasonable amount of Claude's help.*
